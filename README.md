# Triarchal Democracy

A proposed way for a community to decide things together: one Member one vote, optional and
revocable delegation, a public record, and a gated, unpromised dividend. The rules are first drafts
written to be challenged, and this software is early. It has known gaps, listed on the Known limits
page of the project site.

- Live deployment of the software: https://triarchalframework.triarchal-democracy.workers.dev
- The documents (a Charter and ten codes) are in `docs/founding/`.
- The site is in `site/`; the application (Hono on Cloudflare Workers, D1) is in `app/`.
