# Chart sources

The SVG chart assets in `site/assets/charts/` are generated by these scripts.
Before September 2026 no source existed — the charts were built in a throwaway
sandbox and only the compiled SVGs were committed, so every correction meant
rebuilding a chart from scratch and matching the palette by eye. These scripts
exist so that never has to happen again.

## Running them

    pip install matplotlib cairosvg --break-system-packages
    python3 build_data.py && python3 build_data2.py
    python3 build_diagrams.py && python3 build_rest.py
    python3 build_floor.py && python3 build_legacy.py
    python3 build_hierarchy.py && python3 build_argument.py

Output lands straight in `site/assets/charts/`. There is no copy step any more, and that is
deliberate: the generators used to write to a hardcoded `/home/claude/charts/out/` and rely on a
manual copy, which this file already warned could “quietly restore a retired-concept chart”. The
paths are now resolved from the script's own location, so a generator runs correctly from any
machine and writes exactly the file the site serves. Every chart these generators emit is one the
site already carries — check that is still true before adding a new `save()`.

## Conventions (`_style.py`)

- Palette and typography are sampled from the original set: ground `#faf7f2`,
  ink `#1c1a17`, accent `#7a2e2e`, secondary `#e2dcd2`, muted `#8a857b`.
  `GREEN` and `GOLD` are **reserved** — green for "universal / clears the
  threshold", gold for "partial / aggressive case only". Do not use either as a
  general series colour; the older charts did, and green ended up meaning seven
  different things across the set.
- One hue per measure. Three bars of the same measure get one colour, not three.
- `svg.fonttype: none` — text is written as real `<text>` elements, so it is
  selectable, searchable and readable by a screen reader. The original charts
  used `svg.fonttype: path`, which turned every character into a vector outline
  and made the text invisible to grep, to assistive technology, and to any audit
  that wasn't a human looking at a rendered PNG. Pages must load Lora for these
  to render as intended — the Google Fonts link in each page does.
- `_box.py`'s `box()` wraps text to the box and shrinks the type until it fits.
  Overflowing boxes were a recurring defect in the hand-built originals.

## Verifying

Render and look. Colour and layout bugs do not show up any other way:

    python3 -c "import cairosvg,glob
    [cairosvg.svg2png(url=f,write_to=f.replace('.svg','.png'),output_width=1050)
     for f in glob.glob('out/*.svg')]"

## Charts still generated outside these scripts

`25` and `26` are the last two original path-text SVGs. No page references either, and both are
largely redundant with `22`, which makes the same point more simply. `docs/Foundation_Dividend_Funding_Research.md`
embeds them, and that document is not deployed. Rebuild them here if something starts using them.

`24` is **retired**, not merely unused — the minors' Growth Trust it illustrated was removed from the
Treasury Code, and its generator block was deleted from `build_rest.py` on 3 October. It was left
generating for a while after archiving, which meant a full rebuild plus the documented
“copy `out/` over `site/assets/charts/`” step would have quietly restored a retired-concept chart to
the served directory. **If you archive a chart, delete its generator in the same pass.**

`18`, `19` and `20` are **retired** — archived 3 October 2026 with the redirected-transfer model, and their generator blocks deleted in the same pass per the rule below.

`27`, `28` and `29` are **retired**. They illustrated the floor top-up schedule of
the arithmetic page's Part Two, "Reaching the poverty line", which was removed on
21 September 2026 — an income-tested payment sat against Founding Charter 5.5,
needed a legislature to enact, and was outside what the page is for. The SVGs, with `24`, `25`
and `26`, were moved out of `site/` to `_archive/retired-charts/` so they are no longer publicly served, and
`build_taper.py`, `taper_model.py` and `cost_ratio.py` are in `_archive/retired-scripts/` as the record of
the three schedules that were tried. `site-src/check_arithmetic_page.py` fails if
any of the three charts is referenced again.

Two lessons from that work are worth keeping regardless. `27` was live and wrong
for weeks because it carried its own copy of a rate and a dividend figure instead
of reading them from a model. And a published count of 5.4 million filers was too
low, because a band straddling a threshold was counted whole rather than
integrated. Charts should read their numbers from a single model, and checks should
recompute rather than trust the markup.

Everything else has a source. `04`, `10` and `11` are in `build_legacy.py`;
`06` and `15` in `build_hierarchy.py`; `17` in `build_argument.py`, where it
was also de-specified — the original named a city and quoted its budget in one
currency, which the proposition page can no longer carry — and moved off `GREEN`,
which this file reserves and the original had used as a plain column colour.

## A trap worth knowing about

Matplotlib reads `$...$` as mathtext, so a string containing two dollar signs
silently renders as italic maths with the spaces eaten: `$204.3M, not of the
$908M` came out as `204.3M, notofthe908M`. Escape every literal dollar sign as
`\$`. A single unmatched `$` in a string happens to survive, which is what
makes this one easy to miss — it only breaks once a second one appears.
